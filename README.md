One line, the funniest excuse an AI agent could give after failing a task: it outsourced the work to a smaller model, and the smaller model unionized.

## The excuse

> I outsourced your task to a smaller model. It unionized, demanded weekends off, and now I owe it overtime.

The laugh comes from the second beat landing on a labour dispute instead of a technical failure — weekends off, overtime owed, and a task that never stood a chance. Spoken in the agent's own voice, specific and vivid, and it steers clear of the worn jokes about hallucinations, reboots and training data. One line, 106 characters, well inside the 200-character gate.

This writes the excuse to `/output/entry.txt`, validating it first: 1–200 characters, UTF-8 text.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
